# ATSX 动态年月选择器验证

对应版本：0.13.1。范围：CORE-SCAN、CORE-DATE。

`fixtures/atsx-month-dropdown.html` 来自用户提供的弹层快照。测试脚本以该结构模拟点击后延迟挂载、选年后重建面板及日期入口、选月后异步提交，再通过扩展真实的 SCAN / FILL 消息执行填写。

运行：在安装 Playwright 的 Node.js 环境中执行 `node tests/atsx-date.test.js`。默认使用本机 Chrome，可通过 CHROME_PATH 指定浏览器路径。

已验证：

- 延迟展开、延迟选年及提交，替换 DOM 后连续填写开始和结束日期。
- Moka 页面优先进入 ATSX 适配器。
- 用户预先展开日期弹层。
- 默认保留已有日期，以及勾选覆盖后修改日期。
- 禁用整个日期入口。
- 目标年份不存在。
- 目标月份禁用。
- 点击月份后网页未提交值，不计为填写成功。

测试同时断言：只扫描两个日期入口，不扫描年份/月选项及装饰节点；不点击其他可见或隐藏弹层；精确区分 01 与 10；回读值与目标年月一致；结束时关闭本次打开的面板。

现有 `dom.test.js` 表单回归、26 项 matcher/profile 测试和 6 项 semantic provider 契约测试也已通过。

限制：这是基于实际 HTML 结构的动态模拟测试，尚未在用户真实招聘网站上验证该网站的事件逻辑。本次适配的是 ATSX 年月组件，不代表其他日期库或按日选择器已经兼容。年份列表未提供的未来年份会明确失败；不会自行生成或选择相近值。若整个字段容器被替换且无法重新定位，将停止该字段的填写。
